Python: Быстро расшифровать текст (XOR) Python

Скрипт на Python для расшифровки запрятанных символов по ключу:

def decrypt(text, key):
    result = ""
    for char in text:
        result += chr(ord(char) ^ key)
    return result

print(decrypt("SecretString", 0x5A))

Что такое обфускация простыми словами?

Представь, что ты написал понятный текст: string userPassword = "12345";.
Обфускация — это когда программа-запутыватель меняет имена понятных переменных на непонятные кракозябры, например: string a1_xZ = "12345";, чтобы разработчику было сложно прочитать чужой код!
